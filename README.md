# Stock Portfolio Tracker
This project is a Stock Portfolio Management System developed using Python.It allows users to add stocks, track investments, calculate profit/loss,and manage their portfolio efficiently.
## Features
- Add and remove stocks
- Track investment details
- Calculate profit and loss
- Display portfolio summary
- User-friendly interface
